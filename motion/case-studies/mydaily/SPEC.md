# Literally... My Daily App

12 seconds, 30 fps, 1920 x 1080. Silent UI walkthrough for a looping portfolio player. Four 3-second beats; 0.65-second camera moves. Existing mockup asset only. No fictional interactions or performance claims. Data shown belongs to the supplied mockup, not a new measurement.

0s: Plan the day. Task dan ringkasan harian dalam satu tempat.

3s: Know where money goes. Lihat pengeluaran berdasarkan kategori.

6s: Keep the habit going. Check-in membantu membaca konsistensi.

9s: See the daily progress. Tinjau kebiasaan dan progress harian.

Banned: rotating devices, invented UI, count-up results, sound, decorative glow. Primary labels 82px. Mobile layout is separately composed.
