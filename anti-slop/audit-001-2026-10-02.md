# Antislop audit 001

Date: 2026-10-02
Scope: redesigned homepage gallery, project detail pages, copy, responsive behavior, accessibility, and comments.
Mode: AFTER. No findings below have been changed without user approval.

## Findings

1. **HIGH — R-25 / C-4: Small muted text falls below WCAG AA.** Text rendered at 40% cream on `#060706` measures about 3.41:1; 45% measures about 4.07:1. Both fail the 4.5:1 threshold for normal-size text. Instances remain in footer labels and metadata.

2. **HIGH — R-15: Generic project CTAs remain.** `View Case` and repeated `Open Case Study` labels describe a template action rather than the specific destination or evidence the reader will see.

3. **HIGH — R-36 / R-37: Footer copy contains generic portfolio language.** `Creative thinking that ships` and `Designed with Aura DNA` sound like design-template language and do not add verifiable information about the work.

4. **MEDIUM — R-10 / R-12 / R-13: The footer still stacks glass, strong blur, large shadow, and an ambient glow.** These effects are applied together where a flat editorial surface would preserve the visual hierarchy established by the redesigned project content.

5. **MEDIUM — R-07 / R-31: The fixed background grid and noise do not have a documented identity purpose.** They read as generic technical texture because no `DESIGN.md` or equivalent rationale ties them to the portfolio's subject matter.

6. **MEDIUM — R-19: Homepage motion remains dense.** The page still creates 15 ScrollTrigger configurations, including three pinned desktop sections plus universal reveals and parallax. The amount of simultaneous scroll choreography competes with gallery scanning and increases low-end mobile/compositor risk.

7. **LOW — R-11: Pill geometry remains overused.** Navigation actions, tags, social controls, CTA buttons, and dialog actions repeatedly use `rounded-full`, reducing component hierarchy.

8. **LOW — R-31: Several comments narrate layout or use decorative section banners.** Examples include numbered animation banners and comments such as `Floating Glass Card` or `3-Column Grid matching Image 4`; these restate implementation or reference an absent design artifact instead of documenting a constraint.

## Verified positives

- The selected work section now has a visual hierarchy instead of equal text-only cards.
- Project details expose Problem, Approach, and Outcome before the long narrative.
- Gallery and image blocks reflow to one column on narrow screens.
- Interactive controls retain visible focus styles and minimum 44px target sizes in the redesigned areas.
- The project loading state names what is loading and uses `aria-busy`.
- No new result metrics or testimonials were invented.
