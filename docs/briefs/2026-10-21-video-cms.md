# Native portfolio video CMS

Experience mode for public gallery, Operate mode for admin. Preserve existing dark/orange identity and gallery composition. Replace reliance on Instagram playback with owner-uploaded MP4/WebM; Instagram remains an optional destination or legacy embed fallback. Google Drive import is outside this upload-first implementation.

Admin supports batch video drop into unpublished drafts, generated JPEG posters at one second, manually uploaded covers, and a scrubbed-frame cover action. Keep existing title/category/order/draft/publish flows. Video source controls stay visible; external URL entry is secondary. Covers are required before publishing real uploaded videos. Video limit is 40 MiB; image/PDF endpoints remain 4 MiB.

Authenticated, same-origin signing issues one path-specific temporary upload token. Native multipart upload sends the file directly to storage with XHR progress, a 120-second transfer timeout and one automatic retry. A lost response ending in an existing-object conflict is resolved by the same bounded completion validation. No service credentials reach the browser. Existing private bucket size expands only as needed when an admin requests a video upload, preserving MIME restrictions. Uploaded files start in a non-public staging prefix. Completion inspects a bounded Range response, validates actual container bytes and size, then moves to the normal Works media prefix. The gateway authorizes published references or the admin session before issuing a one-hour signed playback redirect, allowing storage to handle seeking rather than proxying entire video bodies.

Public cards preserve posters and captions. At most one sufficiently visible file preview plays muted, inline and looping. Sources load only on eligibility. Hidden tabs, reduced motion, offscreen items and open dialogs pause previews. A card remains a named button even if autoplay fails. Selection opens native controls with muted playback and readable blocked/error status. Instagram-only entries retain the existing iframe/external-link fallback. Carousel advancement stays three seconds and stops while the dialog is open.

Reference: Supabase signed upload and standard upload documentation, https://supabase.com/docs/reference/javascript/storage-from-createsigneduploadurl and https://supabase.com/docs/guides/storage/uploads/standard-uploads . The project rejected the signed resumable endpoint, so the verified standard signed transfer is used without adding dependencies. No new layout, stock imagery, or decorative assets.
