# Visual Design horizontal editorial gallery

Mode: Experience. Refinement of the existing black, orange and Manrope showcase. User requests a single horizontal artwork rail, replacing asymmetric masonry only in homepage Visual Design. Reference names Jeppe Christensen and Studio Ardé guide rhythm; no new reference image was supplied in this request.

Artwork leads. Frames share a common height and derive their widths from each image's intrinsic ratio, without crop or stretch. A 16px gap groups title/category immediately beneath each piece. At typical desktop widths the first artwork sizes the rail for roughly 3.4 visible works; on mobile it targets 84% of the rail width, exposing the next piece. Height bounds protect extreme ratios and narrow screens. All published design works retain CMS order; View all stays beside the heading.

Native touch and trackpad scrolling, proximity snap and mouse dragging are manual only. No autoplay or visible Enlarge controls. A quiet Drag / Swipe to explore hint appears only with overflow. Artwork opens the existing lightbox, while available title links retain their separate destinations. A moved pointer suppresses its trailing click; ordinary clicks remain available. The focusable rail supports Arrow keys, Home and End; existing buttons and title links retain keyboard behavior. Reduced motion skips smooth programmatic scrolling.

Hide demo presentation labels from design captions and the design lightbox count without mutating project data or artwork files. Video and Website / Apps remain unchanged. Stored CMS homepage layouts receive the same gallery treatment through the public renderer.
