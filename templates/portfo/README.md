# Portfo: archived editorial template

Source: https://github.com/gadingg/portfo at `5922cb2a258aef1ffaa6e006d205c7372c4eeb7c`.
Archived on 19 October 2026 at the owner's request.

`source/` preserves the original homepage, compiled CSS, authored CSS, local fonts, scripts, images, and videos. It is outside `public/` and is not an alternate public website. Do not edit the archived source to develop the active site.

Administrators can open the preview from **Arsip template**. Every HTML and asset request requires the existing admin session. The preview rewrites local asset URLs, labels itself as an inactive archive, and blocks fetch/XHR, forms, and frames. Its original live project fetch is intentionally blocked; it retains the fallback example cards. External contact links still point to their original destinations.

Only the What I Do bento markup and its scoped CSS were promoted to the active template. Public homepage data and publication remain managed by the existing CMS.
